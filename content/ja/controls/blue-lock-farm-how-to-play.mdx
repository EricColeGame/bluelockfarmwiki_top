## Blue Lock Farmとは実際に何なのか（そしてなぜループが重要なのか）

Blue Lock Farmは、開発元Finding IllusionsによるRobloxのタイクーン風ゲームで、Blue Lockアニメの設定をソロサッカーのマネーマシンに変えたものです。試合で競う代わりに、ロッカーを購入し、そこからアニメ風の選手をハッチし、その選手たちに自分の区画でサッカーボールを稼がせます。ボールでいっぱいのクレートはCashに変換され、Cashで次のロッカーとアップグレードを購入します。戦闘もPvPのプレッシャーもないので、技術の上限は実質的に効率次第です。どれだけ早くハッチできるか、クレートがどれだけ早く埋まるか、1回の売却がどれだけの価値になるかです。

これがBlue Lock Farmの遊び方の短い説明です。長い説明が重要なのは、このゲームがほぼ完全にメニュー操作中心だからです。新しいプレイヤーはよくロッカーを買い、選手が走り回るのを眺め、クレートを手動で売らなければならないことや、アップグレードが下流のすべてを倍増させることに気づかないままです。最初の1時間の判断は複利で効いてくるので、使い始める前にループを理解しておく価値があります。

| 段階 | すること | 得られるもの |
| --- | --- | --- |
| ロッカーを購入 | ロッカーショップでCashを使う | 選手をハッチするロッカー |
| ハッチ | ロッカーが開くのを待つ | 新しいファーム用選手 |
| 稼働 | 選手が自動でサッカーボールを集める | ボールがクレートに入る |
| 売却 | 満杯のクレートを売却ポイントで売る | Cash |
| アップグレード | Cashをアップグレードとより良いロッカーに使う | より速く、より価値のあるループ |

## Blue Lock Farmの遊び方：操作、カメラ、インターフェース

Blue Lock FarmはRoblox標準の操作体系を使うので、スポーンする前にすでに入力の90%を知っているでしょう。キーボードで歩き、マウスで見回し、ボタンをクリックするか画面のプロンプトキーを押して操作します。開発者はいつでもキーを再割り当てしたりショートカットを追加できるので、下の表と合わない場合は、ゲーム内設定メニューを開いて確認してください。

| 入力 | Robloxのデフォルト割り当て | 農場での役割 |
| --- | --- | --- |
| 移動 | W, A, S, D または矢印キー | 自分の区画とPlazaを歩き回る |
| 視点 | マウス移動 | カメラを回転させる |
| ジャンプ | スペースバー | クレートや小道具を飛び越える |
| スプリント | Shift（Robloxゲームで一般的） | ロッカーと売却ポイント間を速く移動する |
| 操作 | 左マウスクリックまたは画面のプロンプト | 台、ボタン、ショップNPCを使う |
| カメラズーム | マウスホイール | カメラを寄せたり引いたりする |
| メニューを閉じる | Esc | Robloxメニューを終了する；ゲームUIには独自の閉じるボタンがある |

Blue Lock Farmはアクションゲームではなく経営ゲームなので、本当の「操作」はインターフェースのボタンです。それぞれの場所を覚えておけば、毎回のプレイで迷い回る数分を節約できます。

| インターフェース要素 | 場所 | 使う理由 |
| --- | --- | --- |
| ショップ | 画面上のボタン | ロッカーを買い、コードを引き換える |
| コード入力欄 | ショップメニューの下部 | プロモコードを入力する |
| ランキング台 | Plaza | Grade TokensまたはCashで選手をグレードする |
| アップグレードパネル | 拠点の近く | Cashを恒久倍率に使う |
| 売却ポイント | クレート列の横 | 満杯のクレートをCashに変換する |

## ステップバイステップ：最初のロッカーから満杯のクレートまで

すっきり始めたいなら、この順番に従ってください。これは唯一の遊び方ではありませんが、最もよくある初心者の罠を避けられます。つまり、クレートが売られないままで餌を与えられないロッカーを買ってしまうことです。

| 分 | 優先事項 | 重要な理由 |
| --- | --- | --- |
| 0–2 | 区画を歩いて売却ポイントとアップグレードパネルを見つける | Cashがどこで入り、どこで出るかを知る必要がある |
| 2–4 | 最も安いロッカーを買う | 最初のハッチサイクルが始まる |
| 4–8 | 最初の選手に稼がせ、最初のクレートを売る | ループが実際に機能していることを確認する |
| 8–12 | Crate ValueまたはLuckアップグレードを買う | 今後のすべての売上を倍増させる |
| 12–15 | 2つ目のロッカーを買う | 並行ハッチは1つの遅いロッカーより勝る |

1. スポーンして位置を把握する。何かを使う前に、売却ポイント、アップグレードパネル、ロッカーショップを見つける。
2. 最初のロッカーを買う。安いロッカーはハッチが速くコストも低いので、Cashが厳しいうちはまさにうってつけ。
3. ハッチした選手を働かせる。選手は自動でボールを稼ぐので、操作する必要はない。
4. クレートが埋まったらすぐ売る。満杯のクレートを拠点に置きっぱなしにすると、無駄な収入になる。
5. すぐ再投資する。売上はすべてアップグレードか別のロッカーに回すべき。
6. 並行して拡張する。ロッカーを3つ以上持ったら、開封速度アップグレードが元を取れるようになる。

経験者が何度も口にするコツが1つあります。クレートが満杯のまま、大きなロッカー購入のためにCashを貯めないことです。早く売って頻繁にアップグレードする方が、ため込むよりほぼ常に勝ります。

## アップグレード、Grade Tokens、ランキングの説明

アップグレードは、あなたの農場が線形でなくなる部分です。それぞれが異なるボトルネックを対象にしており、間違った順番で買うと進行を遅くする最速の方法になります。

| アップグレード | 改善するもの | 買うタイミング |
| --- | --- | --- |
| Crate Value | クレート売却ごとに得られるCash | 早く、そして頻繁に — すべてを倍増させる |
| Luck | よりレアな選手をハッチする確率 | Crate Valueが安定してきたら |
| Opening Speed | ロッカーがハッチする速さ | ロッカーを3つ以上持ったら |
| Movement Speed | 選手が移動する速さ | 拠点が大きくなったら |
| Base Size | 区画に置けるロッカーとクレートの数 | さらにロッカーを買う直前 |

Grade Tokensは進行パズルの後半です。Plazaの**ランキング台**で使って選手をグレードし、グレードはCash倍率を上げます。Cashでグレードをロールすることもできますが、高ティアのロールは1回につき数百万かかると報告されており、すでに金持ちでない人にとってはGrade Tokensの方が賢い道です。URグレードは最高賞で最大のCash倍率を持つので、実際に残すつもりの選手ができるまでトークンを貯めておく価値があります。

| リソース | 入手方法 | 最適な使い道 |
| --- | --- | --- |
| Cash | 満杯のクレートを売る | ロッカーと恒久アップグレード |
| Grade Tokens | コードとマイルストーン報酬 | ランキング台で選手をグレードする |
| Trait Tokens | コードと報酬 | 選手に特性を付与する |
| Variant Token | コードと限定報酬 | バリアント選手のロール |
| Luck / Cash / Grade Speed Potions | コードと報酬 | 長時間の周回中の時限ブースト |
| Jackpot Token | コードと報酬 | 大きなボーナス支払いのチャンス |

## コード、ブースター、コミュニティリソース

コードはBlue Lock Farmの遊び方において最速のショートカットです。通常なら何時間もの周回が必要なPotionsとTokensを手に入れられるからです。引き換えはショップメニュー内で行います。ショップを開き、一番下までスクロールし、コードを入力欄に貼り付けて、引き換えボタンを押します。入力は慎重に — 余分なスペースや大文字が1つあるだけで、本来使えるコードが無効になります。できるだけコピー＆ペーストしましょう。

以下のリストは2026年9月下旬のコミュニティ報告を反映しています。プロモコードは期限切れになり、開発者はアップデートで報酬を入れ替えるため、これは永久リストではなくスナップショットとして扱ってください。

| コード | 報酬（コミュニティ報告による） |
| --- | --- |
| TRAITS | 25 Trait Tokens |
| ADMINABUSE | 20 Trait Tokens、20 Grade Tokens、Variant Token |
| POLISHER | 1 Jackpot Token |
| COMMUNITY | 3x Cash Potions、3x Grade Speed Potions、3x Luck Potions |
| WEATHER | 5 Grade Tokens、1 Luck Potion |

形式についての簡単な注意：コード一覧によっては「NEW」タグが付いているものがあります。そのタグはラベルであり、コード自体の一部ではありません。引き換えに失敗したら、タグを外して素の単語を試してください。

最新コードについては、ゲームの公式Discordサーバーが最良の情報源で、次に告知とマイルストーン報酬についてはFinding IllusionsのRobloxグループページです。毎日SNSフィードを掘り返したくないなら、コードページをブックマークして週に一度確認すればほぼすべてをカバーできます。また、コードはRobloxアカウントに紐づくので、ランダムなコメント欄のリンクをクリックし始める前に、アカウントセキュリティの基本について[Roblox公式ウェブサイト](https://www.roblox.com/)を確認しておく価値があります — コード詐欺は人気のあるRobloxゲームならどこにでもあります。

## 新しいプレイヤーの進行を遅らせるよくあるミス

- **クレートを満杯のまま放置する。** 満杯のクレートは何も稼ぎません。売ってCashを働かせましょう。
- **最初に最も高いロッカーを買う。** 高価なロッカーは遅いです。品質より量を優先したいです。
- **アップグレードを無視する。** 1つのCrate Valueアップグレードは、序盤ではロッカー1つ分より稼ぐことがよくあります。
- **捨てる選手にGrade Tokensを使う。** 残す価値のある選手をハッチするまで貯めておきましょう。
- **コードをスキップする。** 無料のPotionsとTokensは純粋な利益で、受け取るのに2分しかかかりません。
- **拡張前に作りすぎる。** Base Sizeは置ける量を制限するので、さらにロッカーを買う前にアップグレードしましょう。

## FAQ

**新規アカウントでBlue Lock Farmの遊び方を始めるには？**
まず最も安いロッカーを買い、選手にボールを稼がせ、最初の満杯クレートを売り、そのCashをCrate Valueアップグレードに使います。このサイクルを繰り返し、収入が増えるにつれてロッカーを追加します。

**選手を手動で操作する必要はありますか？**
いいえ。選手はハッチされれば自分でボールを稼ぎます。あなたの仕事はロッカーの購入、クレートの売却、アップグレードの選択です — 移動操作は主に自分の区画とPlazaを移動するためのものです。

**Grade Tokensは何に使いますか？**
Grade TokensはPlazaのランキング台で選手をグレードするために使います。グレードが高いほどCash倍率が大きくなり、URグレードが利用可能な中で最強です。Cashでグレードすることも可能ですが、高ティアでは極端に高額になります。

**Blue Lock Farmのコードはどのくらいの頻度で出ますか？**
新しいコードは通常、アップデート、マイルストーン、季節イベントに合わせて登場します。コミュニティ情報源は2026年9月下旬に5つの有効コードを報告していましたが、信頼できる行動は、各パッチ後に公式DiscordかFinding Illusionsグループを確認することです。

序盤のループ — ロッカー、クレート、売却、アップグレード — を正しく回せば、Blue Lock Farmの遊び方でそれ以降のすべては、当てずっぽうではなく規模の問題になります。
